PROYECTO ACADÉMICO

Acerca de PayTrack

MVP de recordatorios de pago para estudiantes universitarios.

¿Qué problema busca resolver?

PayTrack busca ayudar a estudiantes a centralizar pagos como colegiaturas, tarjetas de crédito, suscripciones y otros gastos, para tener claras sus fechas y montos.

¿Qué estamos probando?

  • Si los estudiantes tienen problemas reales para recordar y organizar sus pagos.
  • Si registrar y consultar pagos es sencillo.
  • Qué recordatorios o funciones valoran más.
  • Si utilizarían la herramienta recurrentemente y pagarían una mensualidad.

Limitaciones de esta versión

Este prototipo guarda datos localmente en el navegador. Los recordatorios se muestran dentro de la página; todavía no envía correos, SMS ni notificaciones cuando la página está cerrada. Tampoco conecta cuentas bancarias ni procesa pagos.

Herramientas sugeridas para la siguiente etapa

Figma para diseño, Glide o una herramienta web sin código para desplegar una versión compartible, y Google Sheets como base de datos inicial. Para recordatorios automáticos se necesitaría configurar un servicio de notificaciones.

Datos de demostración editables. No ingreses contraseñas, números completos de tarjeta ni información bancaria sensible.
PayTrack es un MVP académico para validar una hipótesis. No sustituye los calendarios oficiales ni los avisos de bancos o instituciones.
